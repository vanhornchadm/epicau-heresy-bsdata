# Greater Daemon Horde

1-3 Greater Daemons of the same Chaos god; requires a Daemonic Horde of the same god.

## Composition

- **Chaos God**: one of:
  - **Khorne**: 1-3 [[Bloodthirster (Greater Daemon)]], +200 pts each
  - **Nurgle**: 1-3 [[Great Unclean One (Greater Daemon)]], +200 pts each
  - **Slaanesh**: 1-3 [[Keeper of Secrets (Greater Daemon)]], +200 pts each
  - **Tzeentch**: 1-3 [[Lord of Change (Greater Daemon)]], +200 pts each
