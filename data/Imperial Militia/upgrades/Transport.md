# Transport

Add enough transports to carry the entire formation (Arvus 25 pts each, Rhinos 25 pts per 2, Land Raider 50 pts each; each carries 2 infantry units, Ogryns count as 2); the count is set from the formation.

## Adds

- **Transport**: one of:
  - **Arvus Lighter**:
    - Transports carrying 2 Transport space each: [[Arvus Lighter Orbital Shuttle]], +25 pts each
  - **Auxilia Rhinos**:
    - Transports carrying 2 Transport space each: [[Auxilia Rhino]], +12.5 pts each
  - **Auxilia Land Raider**:
    - Transports carrying 2 Transport space each: [[Land Raider Proteus]], +50 pts each
