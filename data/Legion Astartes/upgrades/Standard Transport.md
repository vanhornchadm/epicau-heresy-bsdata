# Standard Transport

Add enough Rhino Armoured Carriers to transport the entire formation after all other upgrades are chosen. Each Rhino carries 2 Tactical-sized units; one of them may be a Damocles Command Rhino. The count is set from the formation; add this upgrade last, or adjust the transports if you change units afterwards.

## Adds

- Transports carrying 2 Tactical Transport Space each:
  - [[Rhino Armoured Carrier]]
  - 0-1 [[Damocles Command Rhino]]
