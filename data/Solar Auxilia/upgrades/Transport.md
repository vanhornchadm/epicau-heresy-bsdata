# Transport

Add enough transports to carry the entire detachment (infantry units take 1 space, Ogryns 2; Arvus 2, Dracosan 4, Stormlord 8); the count is set from the formation.

## Adds

- **Transport**: one of:
  - **Dracosan Armoured Transport**:
    - Transports carrying 4 Transport space each: [[Dracosan Armoured Transport]], +75 pts each
  - **Stormlord**:
    - Transports carrying 8 Transport space each: [[Stormlord]], +200 pts each
  - **Arvus Lighter**:
    - Transports carrying 2 Transport space each: [[Arvus Lighter Orbital Shuttle]], +25 pts each
